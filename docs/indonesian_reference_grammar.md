## 【A1 基礎入門】

### 1. 詞類基礎：人稱代名詞 (Personal Pronouns)

印尼語的人稱代名詞根據**社交語境親密度**與**語法功能**有嚴格區分：

| 人稱類別 | 代名詞 | 使用時機與社交語境 | 範例句 | 繁體中文解析 |
| :--- | :--- | :--- | :--- | :--- |
| **第一人稱單數** | **saya** | 中立、正式場合或非親密關係使用。 | *Saya membaca buku.* | 我正在讀書。 |
| | **aku** | 親密關係（家人、同儕）或日常口語使用。 | *Aku suka kopi.* | 我喜歡咖啡。 |
| **第二人稱單數** | **Anda** | 正式社交、媒體廣播或公共廣告，不含階級暗示。 | *Apakah Anda suka minum teh?* | 您喜歡喝茶嗎？ |
| | **kamu** | 平輩、熟人、長輩對晚輩使用。 | *Kamu tinggal di mana?* | 你住在哪裡？ |
| **第三人稱單數** | **dia** | 可置於動詞前（主詞）、動詞後（受詞）或介系詞後。 | *Dia menolong saya.* | 他幫助我。 |
| | **ia** | 僅能置於動詞前作為主詞（句首或被動語態前）。 | *Ia akan datang besok.* | 他明天會來。 |
| **第三人稱複數** | **mereka** | 第三人稱複數「他們/她們」，無社會階級區分。 | *Mereka sedang makan.* | 他們正在吃飯。 |
| **第一人稱複數** | **kita** | **包含式**（包含聽者：我 + 你/你們）。 | *Kita harus pergi sekarang.* | 我們（包含你）現在必須走了。 |
| | **kami** | **排除式**（排除聽者：我 + 其他人，不包含你）。 | *Kami akan mengunjungi Bali.* | 我們（不包含你）打算去峇里島。 |

* **💡 易混淆考點**：
  1. **kita vs. kami**：向聽者說話時，若邀請聽者一同行動必須用 *kita*；若向聽者報告「我們這一群人（不包含聽者）」的行程，必須用 *kami*。
  2. **dia vs. ia**：*ia* 絕不可放在動詞或介系詞之後作為受詞（如 ✖ *Saya melihat ia* 為語法錯誤，必須寫成 🗹 *Saya melihat dia*）。

---

### 2. 基本句型：SVO 句型與名詞謂語句 (Basic Clause Types)

1. **SVO 動詞句型**：主詞 (Subject) + 動詞 (Verb) + 受詞 (Object)。
   * *範例*：*Ali [S] membeli [V] mobil [O].*
   * *解析*：Ali（主詞）購買（動詞）汽車（受詞）。
2. **名詞謂語句 (Nominal Clause)**：主詞 + 名詞短語（無須連繫動詞 IS/ARE）。
   * *範例*：*Ali [S] guru [P].*（或可加入連繫詞 *adalah*：*Ali adalah guru.*）
   * *解析*：Ali 是老師。
* **💡 易混淆考點**：印尼語的名詞謂語句不強制要求使用類似英文的 "to be" 動詞；但在正式書面語中，若名詞謂語較長，可加入 *adalah* 或 *ialah* 連接。

---

### 3. 否定系統：bukan vs. tidak (Negation System)

| 否定詞 | 否定對象 | 範例句 | 繁體中文解析 |
| :--- | :--- | :--- | :--- |
| **bukan** | 否定**名詞**、名詞片語或身分資格。 | *Ini **bukan** uang saya.* | 這**不是**我的錢。 |
| **tidak** | 否定**動詞**、**形容詞**或介系詞片語。 | *Saya **tidak** pergi ke sekolah.* | 我**沒有**去學校。 |

* **💡 易混淆考點與常見錯誤**：
  * ✖ 錯誤：*Dia tidak guru.*
  * 🗹 正確：*Dia **bukan** guru.*（*guru* 為名詞，必須使用 *bukan* 否定）。

---

### 4. 基礎介詞與指示詞 (Prepositions & Demonstratives)

* **指示詞 (Demonstratives)**：*ini*（這個/這些，近指）與 *itu*（那個/那些，遠指），**永遠置於名詞之後**。
  * *範例*：*buku ini*（這本書） / *rumah itu*（那棟房子）。
* **處所介系詞 (Locative Prepositions)**：
  * **di**：靜態，表示「在某地」（無移動）。例：*Dia tinggal **di** kota.*（他住在城市裡。）
  * **ke**：動態，表示「朝向/到某地」。例：*Dia berjalan **ke** kota.*（他走路去城市。）
  * **dari**：動態，表示「從某地離開」或來源。例：*Dia berangkat **dari** kota.*（他從城市出發。）
* **💡 易混淆考點**：指示詞置於名詞後；若置於名詞前（如 *Ini rumah*），則變成獨立句子（這是房子）。

---

### 5. 數字、時間與常用問句 (Numbers & Interrogatives)

* **常用疑問詞 (Interrogative Pronouns/Words)**：
  * **apa**（什麼 - 詢問事物）：*Anda membaca **apa**?*（你在讀什麼？）
  * **siapa**（誰 - 詢問人）：*Dia menemui **siapa**?*（他去找誰？）
  * **di mana**（在哪裡 - 詢問地點）：*Di mana rumah Anda?* （你的家在哪裡？）
  * **kapan**（何時 - 詢問時間）：*Kapan Anda berangkat?* （你何時出發？）
  * **berapa**（多少 - 詢問數量/價格）：*Berapa harganya?* （多少錢？）
* **💡 易混淆考點**：詢問人的姓名時，印尼語必須使用 **siapa** 而非 *apa*。
  * 🗹 *Siapa nama Anda?*（你叫什麼名字？）

## 【A2 初級應用】

### 1. 基礎動詞詞綴 (Basic Verbal Affixes)

#### (1) 不及物動詞前綴 `ber-`
`ber-` 前綴派生不及物動詞，常見核心語意包括：
1. **擁有 (Possession)**：*berumur*（有...歲數）、*berguna*（有用的）。
2. **穿戴/使用 (Wear/Use)**：*bertopi*（戴帽子）、*bersepeda*（騎腳踏車）。
3. **從事職業/活動 (Occupation/Activity)**：*bekerja*（工作）、*berbelanja*（購物）。
4. **相互關係 (Reciprocal)**：*bertetangga*（互為鄰居）。
* *範例*：*Anak itu bersepeda ke sekolah.*（那個小孩騎腳踏車去學校。）

#### (2) 及物與不及物前綴 `meN-`（初級形態）
`meN-` 標示主動語態。在初級階段，詞首字母為元音、b、d、g、l、r 時，不發生複雜脫落：
* *me- + lihat* \\(\rightarrow\\) **melihat**（看）。
* *mem- + beli* \\(\rightarrow\\) **membeli**（買）。
* *men- + dengar* \\(\rightarrow\\) **mendengar**（聽）。
* *範例*：*Saya melihat burung itu.*（我看見那隻鳥。）

#### (3) 簡易第三人稱被動式 `di-` (Passive Type 1)
當主詞為受事者（Patient），且執行動作的施事者為第三人稱（*dia/mereka* 或名詞）時，動詞使用前綴 `di-`：
* *句型*：**受詞(主詞) + di-動詞 + (oleh) + 施事者**。
* *範例*：*Buku ini ditulis oleh sekretaris.*（這封信是由秘書寫的。）

* **💡 易混淆考點**：`ber-` 開頭的動詞為不及物動詞，其後**絕對不能直接加受詞**（例如不能說 ✖ *Saya bekerja kantor*，需加介系詞 🗹 *Saya bekerja di kantor*）。

---

### 2. 疑問與連接 (Interrogatives & Conjunctions)

* **進階疑問詞**：
  * **kenapa / mengapa**（為什麼 - 詢問原因）：*Mengapa dia tidak datang?*（他為什麼沒來？）
  * **bagaimana**（如何/怎樣 - 詢問方式或狀態）：*Bagaimana jalan itu?*（那條路狀況如何？）
* **基礎連接詞**：
  * **dan**（和/與） / **atau**（或者） / **tetapi**（但是） / **karena**（因為）。
  * *範例*：*Dia pandai **tetapi** malas.*（他很聰明但是很懶惰。）

---

### 3. 助動詞與情態 (Modals & Aspect Markers)

| 類別 | 詞彙 | 語意與用法 | 範例句 |
| :--- | :--- | :--- | :--- |
| **情態助動詞** | **bisa / dapat** | 能夠 / 可以（能力或客觀條件允許）。 | *Saya **bisa** berbicara bahasa Indonesia.* |
| | **harus** | 必須 / 應該（義務或必要性）。 | *Anda **harus** makan obat ini.* |
| | **boleh** | 可以（獲得許可）。 | *Apakah saya **boleh** masuk?* |
| | **mau / ingin** | 想要 / 打算。 | *Saya **ingin** memesan makanan.* |
| **體貌標記** | **sudah** | 已經（動作已完成/狀態已達成）。 | *Dia **sudah** makan.* |
| | **belum** | 尚未 / 還沒（tidak + sudah）。 | *Saya **belum** siap.* |
| | **sedang** | 正在（動作正在進行中）。 | *Ibu **sedang** memasak.* |

* **💡 易混淆考點**：*tidak boleh* 表示「不可以/禁止」；而 *tidak harus* 則表示「不必/不一定要」。

---

### 4. 日常社交與祈使句 (Social Scenarios & Imperatives)

* **silakan**：用於邀請聽者做對**聽者有利**的事（請/請便）。例：*Silakan masuk.*（請進。）
* **tolong**：用於請求聽者協助做對**說者有利**的事（請幫忙）。例：*Tolong buka pintu ini.*（請幫我開這扇門。）
* **jangan**：否定祈使句（不要/禁止）。例：*Jangan merokok di sini!*（請勿在此吸菸！）

## 【B1 中級精熟】

### 1. 進階詞綴與派生 (Advanced Affixation & Derivation)

#### (1) `meN-` 完整鼻音化同化音變規則 (Nasalization Rules)
`meN-` 中的 `N` 會根據詞根首字母發生同化、脫落或附加：

| 詞首字母條件 | meN- 變體 | 脫落現象 | 詞根與派生範例 | 繁體中文解析 |
| :--- | :--- | :--- | :--- | :--- |
| **a, e, i, o, u** | **meng-** | 無 | *ajar* \\(\rightarrow\\) **mengajar** | 教導 |
| **b, p, f** | **mem-** | **p 脫落**；b, f 保留 | *beli* \\(\rightarrow\\) **membeli**<br>*pakai* \\(\rightarrow\\) **memakai** (*p* 脫落) | 購買<br>使用 |
| **d, t, c, j, z** | **men-** | **t 脫落**；其他保留 | *dengar* \\(\rightarrow\\) **mendengar**<br>*tulis* \\(\rightarrow\\) **menulis** (*t* 脫落) | 聽<br>寫 |
| **s** | **meny-** | **s 脫落** | *sewa* \\(\rightarrow\\) **menyewa** (*s* 脫落) | 租用 |
| **g, k, h** | **meng-** | **k 脫落**；其他保留 | *kirim* \\(\rightarrow\\) **mengirim** (*k* 脫落) | 寄送 |
| **l, r, m, n, w, y**| **me-** | N 脫落 | *lihat* \\(\rightarrow\\) **melihat** | 看 |
| **單音節詞根** | **menge-** | 無 | *tik* \\(\rightarrow\\) **mengetik** | 打字 |

* **💡 k, p, t, s 不脫落特例**：
  1. 外來語/雙輔音開頭：*protes* \\(\rightarrow\\) *memprotes*；*kritik* \\(\rightarrow\\) *mengkritik*。
  2. 複合前綴 `meN-per-`：*p* 不脫落 \\(\rightarrow\\) *memperlebar*。
  3. 語意區分：*mengaji*（誦古蘭經）vs *mengkaji*（學術研討）。

#### (2) 使役與及物後綴對比 (-kan vs. -i)
`-kan` 與 `-i` 的根本差異在於受詞的語意角色（Semantic Role）：
* **-kan**：受詞為被移動、被操作的 **受事者 (Patient)** 或 **受益者 (Beneficiary)**。
* **-i**：受詞為動作發生的 **地點 (Location)** 或 **接收者 (Recipient)**。

| 比較維度 | 後綴 **-kan** | 後綴 **-i** |
| :--- | :--- | :--- |
| **受詞特徵** | 受詞是被移動的事物或受影響者。 | 受詞是接收動作的地點或對象。 |
| **對比範例** | *Buruh memuatkan **beras** ke kapal.*<br>（工人把**米**[受事者]裝載到船上。） | *Buruh memuati **kapal** dengan beras.*<br>（工人給**船**[地點]裝載了米。） |

#### (3) 名詞化系統 (Nominalization)
* **ke-...-an**：派生抽象性質、狀態或領域。例：*sehat* \\(\rightarrow\\) *kesehatan*（健康）；*duta* \\(\rightarrow\\) *kedutaan*（大使館）。
* **peN-...-an**：派生及物動詞的**動作行為過程**。例：*tulis* \\(\rightarrow\\) *penulisan*（撰寫過程）。
* **per-...-an**：對應不及物動詞（`ber-`）的過程/結果，或指領域與集合處所。例：*berkembang* \\(\rightarrow\\) *perkembangan*（發展演變）；*rumah* \\(\rightarrow\\) *perumahan*（住宅區）。
* **💡 -an vs. peN-...-an 考點辨析**：
  * *tulisan*：作品/寫出來的文章（產物/結果）。
  * *penulisan*：撰寫的動作與過程。

#### (4) 強化/使役前綴 `memper-`
加在形容詞前，表示「使受詞具備更高程度的某種性質」（make more...）：
* *besarkan*（放大）vs *memperbesar*（擴大/使之更大）。
* *範例*：*Kita harus **mempercepat** proses ini.*（我們必須**加速**這個流程。）

### 2. 句法進階：被動句型一與被動句型二 (Passive Voice Systems)

印尼語被動語態根據**施事者（Agent）的人稱**嚴格分為兩種類型，此為 UKBI B1 核心考點：

| 被動類型 | 適用人稱 | 語法結構規則 | 範例句 | 繁體中文解析 |
| :--- | :--- | :--- | :--- | :--- |
| **被動型態一 (Pasif 1)** | 第三人稱代名詞 (*dia/mereka*) 或名詞。 | **受詞(主詞) + di-動詞 + (oleh) + 施事者**。 | *Surat ini **ditulis oleh sekretaris**.* | 這封信是由秘書寫的。 |
| **被動型態二 (Pasif 2)** | 第一人稱 (*saya/kami/kita*) 或第二人稱 (*kamu/Anda*)。 | **受詞(主詞) + 施事代詞 + 原形動詞**（**動詞不可加 di- 或 meN-**）。 | *Buku ini sudah **saya baca**.* | 這本書我已經讀過了。 |

* **⚠️ Pasif 2 嚴格限制與常見錯誤**：
  1. 在 Pasif 2 中，施事代詞與原形動詞之間**嚴禁插入任何詞彙**（否定詞、時間標記必須放在代詞之前）。
     * ✖ 錯誤：*Buku ini saya sudah baca.*
     * 🗹 正確：*Buku ini **sudah saya baca**.*
  2. 第一、二稱被動**嚴禁使用 di- 前綴**：
     * ✖ 錯誤：*Buku itu dibaca oleh saya.*
     * 🗹 正確：*Buku itu **saya baca**.*

### 3. 複合句與連接詞 (Complex Sentences & Conjunctions)

1. **讓步子句 (Concessive)**：*meskipun / walaupun*（雖然/儘管）。
   * *範例*：***Meskipun*** *dia amat capai, dia tetap bekerja.*（雖然他非常累，他依然繼續工作。）
2. **目的子句 (Purpose)**：*agar / supaya*（為了/以便）。
   * *範例*：*Rukman mengingatkan **agar** anak buahnya tidak menembak.*（Rukman 提醒部下不要開槍。）
3. **條件子句 (Conditional)**：*jika / kalau / apabila*（如果/假設）。
   * *範例*：***Apabila*** *pemerintah tidak mengambil langkah tegas, **maka** rakyat akan protes.*（如果政府不採取果斷措施，那麼人民將會提出抗議。）

---

### 4. 正式書面語 (Bahasa Baku) 與 UKBI 篇章閱讀結構

在 UKBI 檢定與正式書面語（Bahasa Baku）中，必須遵守以下規範：
* **動詞前綴不可省略**：口語中常省去 *meN-*（如 *membawa* 說成 *bawa*），但在正式書面語與文章閱讀中，必須保留完整的 *meN-* 與 *ber-* 前綴。
* **關係子句標記 yang 的完整使用**：修飾名詞的形容詞或子句，必須使用 *yang* 作為關係引導詞。
  * *範例*：*Orang **yang** duduk di situ adalah presiden.*（坐在那裡的侍衛是總統。）
* **動詞與名詞化轉換**：廣泛使用 `peN-...-an` 表示抽象行為過程（如 *pembangunan*，建設） 以及 `ke-...-an` 表示狀態與領域（如 *kebijakan*，政策），此類派生詞佔據了 UKBI B1 閱讀篇章的主要詞彙。
